# Screenshots

Place **current** publishing screenshots here (or under `fastlane/metadata/android/en-US/images/phoneScreenshots/` for F-Droid).

Suggested:

- Portrait phone captures of Forecast, Hourly, Map, Settings, hazards
- PNG or WebP, no personal data in the status bar if you care about privacy
- Avoid draft/outdated UI

Old development screenshots from early releases were removed from the tree and should not be used for store listings.
